# Portfolio personal v1

Portfolio personal desarrollado con HTML5 semántico y accesible, pensado como primera versión del sitio web profesional de Vicent Jornet, estudiante de DAM en Alzira.

## Páginas

- `index.html` – presentación personal y proyectos destacados.
- `sobre-mi.html` – trayectoria, aficiones y objetivos.
- `proyectos.html` – colección de proyectos del trimestre.
- `cv.html` – formación, competencias e idiomas.
- `contacto.html` – formulario de contacto y enlaces a GitHub y correo.

## Tecnologías

- HTML5
- Git y GitHub
- SVG para imágenes locales
- Accesibilidad y semántica web

## Cómo abrirlo

Se puede abrir directamente en el navegador o servir desde un servidor local.

```bash
python -m http.server 8000
```

Y luego visitar:

```text
http://localhost:8000/
```
